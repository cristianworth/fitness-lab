# Fitness Lab

Aplicativo pessoal para registrar treinos e alimentação. Versão 0.1.0 em desenvolvimento.

Escopo e critérios: [especificação](docs/spec.md). Acompanhe [plano](docs/plan.md) e [decisões](docs/decisions.md).

Requer Node.js 22.12+ (ambiente inicial: 24.20). Após implementação: `npm ci`, `npm run dev`. Dados serão armazenados no navegador, com exportação/importação de backup.
